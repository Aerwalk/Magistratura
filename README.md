# MagSim — Warehouse Simulation System

Симуляция системы перемещения товаров на складе с использованием наземных роботов-транспортировщиков (РТС) и беспилотного воздушного сканера (БВС).

## Требования

- Python 3.10+
- Зависимости (устанавливаются через pip)

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd MagSim

# 2. (Рекомендуется) Создать виртуальное окружение
python -m venv .venv
.venv\Scripts\activate    # Windows
# source .venv/bin/activate  # Linux/macOS

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить симуляцию
python main.py
```

## Управление

| Элемент | Описание |
|---------|----------|
| Поставка с меткой | Добавляет товар известного типа в очередь РТС |
| Поставка без метки | Добавляет товар, который БВС распознаёт и направляет |
| Запрос товара | Создаёт заказ на выдачу товара со склада |
| Демо-заполнение | Заполняет склад случайными товарами |
| Ребалансировка | Перемещает товары ближе к выходу |
| Новый РТС | Создаёт нового робота для указанного материала |
| Новый материал | Добавляет новый тип материала с выбором цвета |
| Режим редактирования | Вкл/выкл редактирование карты (добавление/удаление полок, смена точек выхода/приёма/забора) |
| Расширить карту | Изменяет размер склада (ширина до 30, высота до 20) |
| Экспорт в Excel | Выгружает статистику по товарам в .xlsx |

## Горячие клавиши

- Левая кнопка мыши на карте: просмотр информации о полке
- В режиме редактирования: добавить/удалить полку
- Правая кнопка мыши на карте: контекстное меню (точка выхода, приёма, забора, удаление полки)
